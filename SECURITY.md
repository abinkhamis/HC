# Security / الأمان

- **لا تفتح Issue عامًا للثغرات.** استخدم «Report a vulnerability» في تبويب Security بالمستودع (GitHub private vulnerability reporting).
- Please do **not** open a public issue for security problems. Use "Report a vulnerability" under the repository's Security tab.
- Never commit real personal data, databases (`data/`), uploaded files (`storage/`) or passwords.
